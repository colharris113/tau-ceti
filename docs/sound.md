# Sound System

SID usage and a breakdown of every effect in the game.

---

A complete analysis of how sound is generated, broken down by effect, using the SID chip.

## SID Chip Usage

Tau Ceti uses the MOS 6581 SID chip for sound effects. Unlike many games of its era, Tau Ceti does not include music - only sound effects are used.

> [!NOTE]
> **Note:** The game focuses on atmosphere through visual effects rather than music. Sound effects are minimal but effective.

### SID Registers Accessed

| Register | Address | Purpose |
|---|---|---|
| $C000-$C002 | Voice 1 (Frequency) | Laser fire sound |
| $C003 | Voice 1 (Control) | Attack/decay/sustain/release |
| $C004-$C006 | Voice 2 (Frequency) | Missile launch sound |
| $C007 | Voice 2 (Control) | Attack/decay/sustain/release |
| $C008-$C00A | Voice 3 (Frequency) | Collision/explosion sound |
| $C00B | Voice 3 (Control) | Attack/decay/sustain/release |
| $C011 | Filter control | Low-pass filter for atmosphere |
| $C01F | Output control | Mix voices to output |

## Sound Effects Breakdown

### 1. Laser Fire

A short, sharp tone generated by Voice 1 of the SID chip. The frequency sweeps rapidly from high to low, creating a "pew" sound.

```text
Laser Sound Parameters:
  Voice: 1
  Frequency: $FF00 -> $8000 (sweep down)
  Waveform: Triangle
  Attack: Fast
  Decay: Medium
  Sustain: None
  Release: Fast
```

### 2. Missile Launch

A rising tone generated by Voice 2, simulating the whoosh of a missile launching.

```text
Missile Sound Parameters:
  Voice: 2
  Frequency: $4000 -> $FF00 (sweep up)
  Waveform: Sawtooth
  Attack: Medium
  Decay: Long
  Sustain: Low
  Release: Medium
```

### 3. Flare Deployment

A brief burst of noise generated by Voice 3, simulating the pop of a flare being deployed.

```text
Flare Sound Parameters:
  Voice: 3
  Frequency: $C000 (fixed tone)
  Waveform: Noise
  Attack: Instant
  Decay: Short
  Sustain: None
  Release: Instant
```

### 4. Collision/Explosion

A loud, harsh sound generated by Voice 3 with noise waveform, simulating an explosion.

```text
Explosion Sound Parameters:
  Voice: 3
  Frequency: $0000 (noise mode)
  Waveform: Noise
  Attack: Instant
  Decay: Very long
  Sustain: High
  Release: Long
```

### 5. Proximity Mine Detonation

A deep, rumbling explosion sound with a longer decay than regular collisions.

```text
Mine Sound Parameters:
  Voice: 1 + 3 (dual voice)
  Frequency: Low sweep on Voice 1, noise on Voice 3
  Waveform: Triangle + Noise
  Attack: Instant
  Decay: Very long
  Sustain: High
  Release: Very long
```

## Sound Generation Process

```text
Sound Trigger Sequence:
  1. Event occurs (laser fire, missile launch, etc.)
  2. Set SID register values for the effect
  3. Start voice by setting control register bit
  4. Wait for decay to complete
  5. Stop voice by clearing control register bit
  6. Return to main game loop
```

## Performance Considerations

Sound effects are generated on-demand rather than continuously, which minimizes CPU usage. The SID chip handles the audio synthesis independently of the 6502 processor.

| Optimization | Description |
|---|---|
| On-demand generation | Sounds only play when triggered, not continuously |
| Short duration | Effects are brief to minimize CPU time |
| No music | No continuous audio stream to maintain |
| Preset parameters | All sound parameters are pre-calculated |

## Summary

Tau Ceti's sound system uses the SID chip for minimal but effective sound effects. Four distinct effects (laser, missile, flare, explosion) cover all gameplay events, with no music to distract from the visual experience.
