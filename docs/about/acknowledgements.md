# Acknowledgements

*Tau Ceti* was designed and written by **Pete Cooke**, converted to the Commodore 64 by **John Twiddy**, and published by **CRL Group PLC** in 1986. The game's economy — one city, one screen, one record table, and a set of rules that fit together — is the reason this guide exists. Any insight on these pages belongs to them; only the mistakes are mine.

The Commodore 64 port is the subject because it is the version whose code I could read closely. The Spectrum, Amstrad, Atari and Amiga versions are different programs with the same design, and readers who know them may notice both agreements and divergences.

## Tools

- **[VICE](https://vice-emu.sourceforge.io/)** — the emulator used to run the original, capture memory and check behaviour on screen.
- **[py65](https://github.com/mnaberez/py65)** — the 6502 decoding tables used by the re-disassembler.
- **[MkDocs](https://www.mkdocs.org/)** and **[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)** — used for the original site edition.

## Form

The presentation is openly modelled on **Mark Moxon's** code guides to *Elite* and *The Sentinel*:

- [Elite on the BBC Micro](https://elite.bbcelite.com/)
- [The Sentinel on the BBC Micro](https://thesentinel.bbcelite.com/)

Those sites demonstrate that a game's code can be explained to a general reader without diluting the technical detail. The routine pages, the per-article "why it works" sections and the habit of showing the actual instruction stream are borrowed from them with gratitude.

## The game

If you have not played *Tau Ceti*, the 1986 original is still the best introduction to what this guide is describing. The modern remake that accompanies this analysis is a separate project and is not required reading.

*Tau Ceti* remains the copyright of its rights holders. This guide is an independent, non-commercial work of analysis, unaffiliated with CRL or the original authors. It reproduces no original graphics, sound or in-game text; the Source guide shows disassembled routines for analysis and commentary, and the font figure is an analytical re-rendering of the message glyphs.
