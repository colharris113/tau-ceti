# Damage

**Address** `$4951-$4989` · **Group** Combat

Shared by lasers and everything else. Subtracts the damage in A from byte 7. On underflow it clears byte 8, sets the death sound counter, marks byte 0 dying, and for armed types adds one to the 16-bit kill count at `$03A5`/`$03A6`. Finally it sets `$0359` = `$FF` for the screen flash. A record whose byte 7 is already negative is immune.
