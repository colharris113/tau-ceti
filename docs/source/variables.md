# Variables

The game keeps almost everything in the zero page and the first few pages of RAM. These are the values the routines in this guide read and write; names are ours, addresses are the game's.

## Flight

| Address | Name | Notes |
| --- | --- | --- |
| `$0338` | **Launch heading (low)** | Low eight bits of the ship's heading. LAUNCH adds `$20` - 32 steps of 512, or 22.5 degrees - and carries into `$0339`. |
| `$0339` | **Launch heading (high)** | Ninth bit of the heading; toggled on launch so the 22.5-degree step wraps correctly. |
| `$0340` | **Frame counter** | BCD counter of frames within the second, 0-`$49`. At `$50` the clock ticks. |
| `$0341` | **Seconds** | BCD seconds, 0-`$59`. |
| `$0342` | **Minutes** | BCD minutes, 0-`$59`. |
| `$0343` | **Hours** | BCD hours, 0-`$23`. |
| `$0344` | **Altitude** | 0-`$BF`. Zero is the ground; docking altitude is 28 (`$1C`). |
| `$0345` | **Fuel (low byte)** | Low byte of the 16-bit fuel value. The burn routine keeps the low-byte result even when an underflow clears the high byte. |
| `$0346` | **Fuel (whole units)** | High byte of the fuel value. Full is `$BF`, just under 192 units; LAUNCH refuses at zero. |
| `$0353` | **Speed** | 0-`$BF`. Divided by 8 to get the fuel burn, and tested for zero when deciding the ship is at rest. |
| `$0377` | **Shield** | 0-`$BF`, full at the start of a game. Regenerates one point a second while airborne and not docked. |
| `$039E` | **Tank ruptured** | Non-zero adds 96 to the per-second fuel burn. |
| `$03A2` | **LOW FUEL flag** | Set once when the fuel high byte reaches `$20`; the watch routine prints the message for value 1 and then increments it. |
| `$03A3` | **NO FUEL flag** | Set when fuel underflows. Also drives the stranded state on the ground. |

## Docking

| Address | Name | Notes |
| --- | --- | --- |
| `$0381` | **Dock refused** | Set to `$FF` when a docking attempt fails the altitude or aim test. |
| `$0396` | **Dock state** | 0 in flight, `$80` after a normal dock, 1 when stranded with an empty tank on the ground. |
| `$0398` | **Docked cell (low)** | Low byte of the docked building's cell, copied on docking and used as the ship's position on launch. |
| `$0399` | **Docked cell (high)** | High byte of the docked building's cell. |
| `$039B` | **Jump pad docked** | Set to `$FF` when the docked building is type 16, the jump pad. |
| `$03A4` | **Docked type** | Record byte 0 of the docked building, copied at `$2C4E`. |

## Combat

| Address | Name | Notes |
| --- | --- | --- |
| `$0347` | **Laser heat** | 0-`$BF`. Each shot adds `$0C`; at `$B0` or above the laser will not fire. |
| `$034A` | **Flag mask** | Eight bytes, 64 bits, tested by the helper at `$3D18`. |
| `$0358` | **Missiles** | Missile count, eight at the start of a game; decremented by a launch. |
| `$036E` | **Bolt timer** | Zero when the laser is ready. Firing sets `$80`; the low seven bits then count the bolt's 22-frame flight. |
| `$0370` | **Laser lockout** | While non-zero the laser cannot fire. |
| `$0386` | **Last on-screen target** | Viewport candidate whose projected width reaches the centre columns. The painter copies it to `$0388`/`$0389` after finishing its pass. |
| `$0388` | **Missile target** | Pointer the missile launch routine reads. Zero means no lock; cleared on a new game and after a jump. |
| `$038A` | **Viewport laser candidate** | Candidate set by the tighter raster test at `$30F2`. The painter copies it to `$038C`/`$038D` after finishing its pass. |
| `$038C` | **Laser target** | Pointer resolved when the bolt lands; the hit goes to this record and no other. |
| `$03A5` | **Kill count (low)** | Incremented by the damage routine for every armed type destroyed. |
| `$03A6` | **Kill count (high)** | High byte of the kill count. |
| `$03BF` | **Provocation latch** | Set by a laser (`$341E`) or a missile launch (`$48F6`) and cleared when a city loads. Static defences ignore the ship until it is set. |

## Messages

| Address | Name | Notes |
| --- | --- | --- |
| `$0383` | **Message read cursor** | Next slot in the `$0C00` ring buffer to print. |
| `$0384` | **Message write cursor** | Next slot in the `$0C00` ring buffer to fill. |
